# Contributing

This guide is maintained from a real device run — contributions that keep it
accurate are welcome.

## Most useful contributions

- **Mirror status reports** — KDZ/tool mirrors die constantly. If a link in
  [docs/01](docs/01-files-and-preparation.md) is dead, or you found a *working
  header-verified* source for early-Oreo H930/US998 KDZs, open an issue.
- **Model reports** — tested on LG-H930DS. If you ran this on H930G, US998,
  V300*, or l01k, report what worked/differed (issues or PRs).
- **Version updates** — newer LOS/Magisk/LSPosed/ViPER/PIF releases verified
  working on joan → PR the tested-version matrix in doc 04.
- **Corrections** — anything that didn't match your device.

## Ground rules

- **Verification over vibes.** If you suggest a file/mirror, include the KDZ
  header version or a checksum — unverified firmware recommendations are how
  people brick.
- No binary uploads of copyrighted firmware/KDZs into the repo — links only.
- Keep the docs factual: what you ran, what happened, device model, versions.
